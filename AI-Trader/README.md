# AI-Trader Website

Files:
- index.html
- style.css
- script.js
- images/logo.webp
- images/hero.webp

Open `index.html` in a browser to preview the site locally.

For GitHub Pages:
1. Create a GitHub repository.
2. Upload these files/folders.
3. Go to Settings -> Pages.
4. Choose `main` branch and `/ (root)`.
5. Save and wait for the Pages URL.
